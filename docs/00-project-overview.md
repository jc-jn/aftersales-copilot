# 00. 项目总览

## 1. 项目定位

AfterSales Copilot 是面向 3C 电商的智能售后工单系统，目标是在保留传统工单系统可控、可审计、事务一致性的基础上，用 AI 降低客服分类、检索政策、查询订单和撰写回复的重复工作。

项目主要用于 Java 后端实习简历与面试展示，计划 4 周完成，每天约 4 小时。设计优先级依次为：可运行、业务闭环、Java 后端含量、AI 可解释性、工程化展示、功能数量。

## 2. 要解决的问题

传统售后处理通常存在以下问题：

- 用户描述不完整，客服需要反复询问订单号、故障现象、收货时间等信息。
- 不同商品、购买时间和故障类型对应不同政策，人工检索速度慢且容易遗漏。
- 重复问题占比较高，客服需要反复编写相似回复。
- 大模型直接执行退款存在幻觉、越权、重复执行和不可审计风险。
- 普通 RAG 演示只回答问题，没有与订单、物流、质保和工单状态联动。

本项目通过“AI 建议、Java 决策并执行”的协作方式解决这些问题。

## 3. 产品角色

| 角色 | 主要能力 |
|---|---|
| 消费者 `CUSTOMER` | 登录、查看模拟订单、创建工单、补充信息、与 AI/客服对话、确认或拒绝处理方案、查看售后进度、评价 |
| 客服 `AGENT` | 查看工作台、领取/接收工单、查看 AI 分析和证据、编辑并发送回复、创建处理提案、推进状态、转派、结案 |
| 管理员 `ADMIN` | 用户与客服管理、商品/订单模拟数据、分配规则、知识库、售后规则、模型配置、统计和审计 |

## 4. MVP 业务闭环

1. 管理员准备商品、SKU、订单、物流、质保规则和售后知识文档。
2. 消费者从自己的已支付订单中选择订单项，创建售后工单。
3. Java 持久化工单并发送 `ticket.ai.analyze.requested.v1` 消息。
4. Python 消费任务或由 AI 适配器接收任务，完成意图分类、紧急度、信息抽取和知识检索。
5. Java 保存 AI 分析结果，并按负载自动分配客服；失败时仍可人工处理。
6. 客服查看订单事实、AI 回复建议和知识引用，编辑后发送给用户。
7. Python 可以调用只读工具查询订单、物流、质保；写操作只能生成处理提案。
8. 用户或客服确认提案后，Java 校验权限、工单版本、订单状态、金额上限和幂等键，在事务中执行模拟售后操作。
9. 工单解决后异步生成摘要；用户评价；工单关闭。

## 5. 成功标准

### 5.1 功能标准

- 四类售后都能走通至少一条正常流程和一条拒绝/取消流程。
- AI 分析失败、超时或余额不足时，工单仍能人工处理。
- RAG 回答展示引用文档、章节和片段，检索不到时明确转人工，不编造政策。
- AI 无法直接修改 MySQL；所有业务写操作均有 Java 审计日志。
- Docker Compose 能启动依赖服务，README 能让新环境完成演示。

### 5.2 可量化标准

| 指标 | MVP 目标 |
|---|---|
| 工单列表普通查询 P95 | 本地环境小于 300ms |
| 非首 Token 的 SSE 连续输出间隔 | 正常网络下尽量小于 1s |
| AI 首 Token 延迟 | 云模型正常时小于 5s，记录实际值而不虚构承诺 |
| RAG 引用覆盖率 | 评测集中需要政策依据的问题，回答必须含至少一个有效引用 |
| 高风险写操作 | 100% 经过确认令牌、权限校验和幂等校验 |
| 核心 Java 服务测试 | 状态机、幂等、权限、金额校验必须覆盖 |
| AI 评测集 | 至少 40 条，其中 10 条无答案/越权/提示注入用例 |

## 6. 非目标

- 不训练基础大模型，不以算法研究为目标。
- 不接真实支付、退款、快递、短信和电商开放平台。
- 不实现完整商城、购物车、营销、发票和仓储系统。
- 不使用多智能体炫技替代确定性业务流程。
- 不在 MVP 中实现语音客服、数字人、多语言、OCR 图片故障诊断。
- 不宣称 AI 自动批准退款；AI 只提供分类、检索、建议和提案。

## 7. 名词表

| 名词 | 定义 |
|---|---|
| 工单 Ticket | 用户针对一个订单项提交的一次售后请求，是本系统主聚合根 |
| 处理提案 Proposal | AI 或客服建议执行的退款、退货退款、换货或维修方案，本身不改变业务状态 |
| 执行 Execution | Java 服务在确认、校验和幂等保护后对模拟退款/换货/维修记录进行的状态变更 |
| AI 分析 Analysis | 工单分类、紧急度、情绪、结构化字段、缺失信息和建议回复 |
| 知识库 Knowledge Base | 售后政策、商品手册、FAQ 等可检索资料及其版本 |
| 引用 Citation | 回答依赖的知识片段标识、文档标题、章节和相似度信息 |
| 人工接管 | AI 不确定、无依据、敏感或失败时交由客服处理 |
